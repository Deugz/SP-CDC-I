# A/B Testing

Définition :
Méthode expérimentale quantitative consistant à comparer simultanément deux versions d’une interface auprès de segments d’utilisateurs distincts afin d’identifier la version la plus performante selon un indicateur défini.

Indicateurs mesurés :

Taux de conversion

Taux de clic

Taux de rebond

Engagement utilisateur

Utilité dans le projet :
Ce test est principalement utilisé en phase d’optimisation continue pour améliorer la performance commerciale ou l’expérience utilisateur après le lancement.
