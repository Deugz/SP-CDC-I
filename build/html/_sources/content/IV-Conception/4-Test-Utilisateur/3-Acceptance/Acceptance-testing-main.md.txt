# Test d'Acceptabilité

Définition :
Processus formel de validation réalisé par les utilisateurs finaux ou les commanditaires du projet afin de vérifier la conformité du produit aux exigences fonctionnelles définies dans le cahier des charges.

Objectifs :

Vérifier l’adéquation aux besoins métiers

Valider les fonctionnalités clés

Autoriser la mise en production

Utilité dans le projet :
Ce test constitue une étape décisionnelle majeure avant le déploiement officiel du produit.
