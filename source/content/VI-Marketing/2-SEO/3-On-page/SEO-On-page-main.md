# On-Page


Il concerne tout ce qui se trouve directement sur les pages.

Principaux éléments :

Balises Title et Meta Description

Balises H1, H2, H3…

Optimisation du contenu (qualité, pertinence, intention de recherche)

Maillage interne

Optimisation des images (balises ALT)

Expérience utilisateur (UX)

👉 Objectif : rendre chaque page pertinente et optimisée pour une requête donnée.
