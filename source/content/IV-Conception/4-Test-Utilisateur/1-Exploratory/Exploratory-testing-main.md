# Tests Exploratoirs

Définition :
Méthode qualitative visant à observer les comportements spontanés des utilisateurs face à un concept, une maquette ou un prototype préliminaire, sans scénario strictement défini.

Objectifs :

Identifier les besoins implicites

Comprendre les représentations mentales des utilisateurs

Détecter les incompréhensions précoces

Utilité dans le projet :
Ce test est particulièrement pertinent en phase amont (UX research), lorsque les hypothèses de conception doivent être validées avant le développement.
