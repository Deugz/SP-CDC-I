# Tests d'Utilisation

Définition :
Méthode d’évaluation consistant à observer des utilisateurs représentatifs accomplir des tâches précises afin de mesurer l’efficacité, l’efficience et la satisfaction.

Indicateurs mesurés :

Taux de réussite

Temps d’exécution

Nombre d’erreurs

Niveau de satisfaction perçue

Utilité dans le projet :
Ce test intervient généralement sur des wireframes, prototypes interactifs ou versions bêta afin d’améliorer l’ergonomie et la fluidité du parcours utilisateur.
